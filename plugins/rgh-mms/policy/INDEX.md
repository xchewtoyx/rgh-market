# Policy pack index — canonical defer map

Single map of **topic → one canonical file → consumers that defer to it**.
Authors and reviewers use this instead of grepping to decide where a claim
belongs. Do not duplicate policy here; link only.

Consumers are roles, workflows, profiles, skills, and related harness docs that
point at the canonical file (spot-checkable by grep). Generated adapter copies
under `.claude/` are omitted — they regenerate from harness/skill sources per
[`ARCHITECTURE.md`](../ARCHITECTURE.md) `## Generated adapters` (via
[`scripts/generate-adapters.py`](../scripts/generate-adapters.py); see
[`harnesses/README.md`](../harnesses/README.md)).

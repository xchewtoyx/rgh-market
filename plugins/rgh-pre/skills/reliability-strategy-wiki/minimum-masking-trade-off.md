type: concept
title: Minimum-Masking Trade-Off
description: >
  A prioritisation framework for social environments: identify the smallest
  masking set each context truly requires, meet only that minimum, and
  reclaim authenticity everywhere else — trading acute social-performance
  cost only where the environment demands it.
sources:
  - title: "The Unmasking Workbook for Autistic Adults"
    resource: "The Unmasking Workbook for Autistic Adults (Jessica Penot), ch. 8"
---

Traditional social-skills training optimizes for neurotypical comfort. Reverse
social skills training inverts the objective: maximize comfort and
authenticity while meeting only the **minimum** social requirements each
environment actually imposes.

Audit three questions per context:

- Where can you safely unmask completely?
- Where do you still need to perform "somewhat normal"?
- What is the **smallest** skill set that satisfies that context?

Example minimum set for high-anxiety networking: smile when approached, brief
eye contact, monitor facial expression while speaking — not full neurotypical
performance. Once minimums are named for work meetings, a child's school, or
similar, the rule is: be completely unmasked everywhere else (stimming,
info-dumping, glimmers) when with trusted family, partner, or solitude.

This implements [acute vs. chronic objectives](acute-vs-chronic-objectives.md)
in social life: acute "appear acceptable" demands get the smallest necessary
slice; chronic objectives — autonomy, sustainable comfort, authentic
connection — get protected everywhere the environment allows. Pair with
[personal priority over social default](personal-priority-over-social-default.md)
when deciding which contexts are worth any masking cost at all.

title: Interlocking State Dimensions
description: >
  Feelings, thoughts, body sensations, and behaviors form mutually
  reinforcing loops where any one dimension can trigger the others —
  so a partial state reading may miss the cascade already underway.
sources:
  - title: "The Mindful Way through Depression: Freeing Yourself from Chronic Unhappiness"
    resource: "The Mindful Way through Depression (Mark Williams, John Teasdale, Zindel Segal, Jon Kabat-Zinn), ch. 1"
---

Depression and similar spirals are not single-channel events. Four
dimensions — **feelings**, **thoughts**, **physical sensations**, and
**behaviors** — interact and reinforce each other. Any one part can start
the downward spiral; repeated cycling strengthens the pattern until
eventually **any one element alone can trigger the whole cascade** — a
fleeting failure thought triggering fatigue, a small comment triggering
guilt and inadequacy themes.

Spirals triggered by small events can feel like they "come out of nowhere"
because the initiating signal was in a different dimension than the one
being monitored.

For telemetry:

- Reading only mood may miss body bracing or behavioral withdrawal already
  feeding it; reading only thoughts may miss somatic threat signals already
  registered.
- Irritability often clusters with sadness and can be more prominent than
  sadness itself — especially in young people — so a "not sad" self-report
  may still be a depressive reading.
- Unhappiness itself is normal; the telemetry shift is when harsh
  self-views switch on and recruit more negative thought schemes.

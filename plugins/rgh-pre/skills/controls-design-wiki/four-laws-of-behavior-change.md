---
type: concept
title: Four Laws of Behavior Change
description: >
  A four-lever framework for designing or breaking habits: make cues obvious
  or invisible, cravings attractive or unattractive, responses easy or
  difficult, and rewards satisfying or unsatisfying.
sources:
  - title: "Atomic Habits: Tiny Changes, Remarkable Results"
    resource: "Atomic Habits (James Clear), ch. 3; ch. 15"
---

Every habit runs a four-step loop: **cue** (information predicting reward),
**craving** (motivation for the state change the habit delivers — not the
habit itself), **response** (the performed action, gated by ability and
friction), and **reward** (satisfies craving and teaches the brain what to
repeat). If any stage fails, the behavior won't stick.

**To build a good habit:**
1. Cue → make it obvious ([environmental reminder placement](environmental-reminder-placement.md), [habit stacking](habit-stacking.md))
2. Craving → make it attractive
3. Response → make it easy ([law of least effort](law-of-least-effort.md), [friction shaping](friction-shaping.md))
4. Reward → make it satisfying ([cardinal rule of behavior
   change](cardinal-rule-of-behavior-change.md), [habit completion
   reinforcement](habit-completion-reinforcement.md), [streak
   tracking](streak-tracking.md))

**To break a bad habit** — invert each law:
1. Cue → make it invisible (reduce exposure)
2. Craving → make it unattractive (reframe benefits of avoidance)
3. Response → make it difficult ([commitment device](commitment-device.md), friction)
4. Reward → make it unsatisfying

Habits are reliable solutions to recurring environmental problems; offloading
repeatable tasks to automatic routines frees conscious attention for what
needs it. [Habit loop replacement](habit-loop-replacement.md) swaps only the
response while keeping cue and reward — a targeted application when an
existing loop already runs but the routine is unwanted.

**B = MAP**: Behavior requires all three at once:
- **Motivation** — desire to do the behavior.
- **Ability** — capacity to do it (perceived or actual).
- **Prompt** — cue that triggers the attempt.

Good and bad habits use the same mechanics; feelings differ, components do not.
"No prompt, no behavior" — motivation and ability are background levels;
prompts are discrete events. Removing a visual cue (hotel snack basket hidden
in a cabinet) can stop a habit when M and A cannot be moved.

## The Action Line

Plot ability (easy → hard) against motivation (low → high). A curved **Action
Line** divides the space: above it, a prompt produces behavior; below it, the
same prompt fails. A habit that sticks reliably sits above the line when
prompted.

**Compensatory relationship:** weak motivation needs high ability (easy
behavior); hard behavior needs strong motivation. The easier a behavior is,
the more likely repetition makes it automatic — applies to scrolling and
tidying alike.

## Using the model

Diagnose misses with [prompt-ability-motivation troubleshooting
order](prompt-ability-motivation-troubleshooting-order.md). Design new
habits via [anchor moment design](anchor-moment-design.md) (prompt),
[starter step scaling back](starter-step-scaling-back.md) and [ability chain
diagnosis](ability-chain-diagnosis.md) (ability). Stop habits via [behavior
change masterplan](behavior-change-masterplan.md). The model has no character
axis — treat outcomes as design data in a personal change lab.

Teaching script (two minutes): draw M vertical, A horizontal; place an example
behavior; draw the Action Line; summarize that all three elements must
coincide.

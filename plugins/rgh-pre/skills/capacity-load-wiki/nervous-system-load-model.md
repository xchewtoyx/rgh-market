Some people's filtering of ambient sensory, social, and informational input
is thinner than the baseline a shared environment, schedule, or plan is
implicitly designed around — described in the source as a nervous system
"on the outside of the body." The practical consequence for capacity
planning is not that the person has less capacity in some fixed sense, but
that their capacity depletes faster per unit of ambient input, so plans
built on a "typical" depletion rate (a workday, a week, a shared routine)
will overshoot for them well before the plan's own checkpoints say it
should.

This changes how saturation and headroom should be estimated: headroom
remaining can't be read off elapsed time or task count alone, because the
conversion rate from input to depletion is itself higher. It also means
recovery has more ground to make up per unit of prior activity — see
[saturation cascading across dimensions](cross-dimensional-saturation-cascade.md)
for how unaddressed depletion in one dimension compounds into others, and
[masking as a hidden capacity drain](masking-as-hidden-capacity-drain.md)
for a mechanism that raises the depletion rate further. Structural
**hyperconnectivity** and elevated resting default-mode activity can also
raise baseline idle draw before any environmental input arrives — see
[elevated baseline cognitive idle cost](elevated-baseline-cognitive-idle-cost.md).

The same thinner-filtering model also lowers the *threshold* before a
stress state is entered, not only the rate of ongoing depletion: a nervous
system with less flexible ("rigid") adaptation tips into an activated
stress state at a lower level of cumulative input than a more flexible one
would. This activation is not always the obviously visible kind (agitation,
restlessness) — it is at least as likely to present as freeze or
disengagement, which is easy to misread as calm or low load from the
outside precisely when saturation has already been reached. A capacity
estimate that only watches for visible activation will systematically miss
this quieter saturation state. This lower-threshold, two-sided pattern is
formalized in the [window of tolerance](window-of-tolerance.md): a
narrower band between hyperarousal and hypoarousal thresholds.

The thin-filtering effect isn't limited to sensory input either — the
source describes an analogous pattern in the emotional dimension via a
"porous skin" metaphor: heightened, unshielded absorption of other
people's emotional states and ambient emotional atmosphere, which drains
capacity the same way unfiltered sensory input does even though nothing
about the person's own emotional situation has changed. The model
generalizes across whichever dimension the filtering is thin for, not just
the sensory one.

---
type: concept
title: Trait Label Reframing
description: >
  Deliberately replacing a pejorative trait label — especially one
  internalized from others — with an accurate strength-based description
  and a reason to value that quality.
sources:
  - title: "Unmasking Autism Audiobook Companion"
    resource: "Unmasking Autism Audiobook Companion (Devon Price, PhD), Reframing worksheets (pp. 11–13)"
---

When a trait has been named negatively — by others or by an internalized
voice — a direct relabeling exercise can loosen the grip of the old word.
The simplest form is a two-column swap: old label on one side, alternative
framing on the other (e.g., "stubborn" → assertive, persistent; "distractible"
→ perceptive; "anxious" → cautious). The swap is not forced positivity;
each pair names the same underlying behavior from a less punitive angle.

A richer version uses three columns:

1. **I was told I was:** the pejorative label as received.
2. **But actually I am:** a more accurate, neutral, or strength-based
   description of the same trait.
3. **I value this quality in myself because:** concrete reasons the
   reframed trait serves the person or others.

Example: "arrogant" → confident, principled, independent — because it
helps stand up for what's right and often means being first to name a
problem. "Cold and unfeeling" → analytical, rational, thoughtful — because
it supports noticing what others miss and not being swept away in the
heat of the moment. "Sensitive" → perceptive, emotionally attuned,
compassionate — because it makes mistreatment visible and supports reading
a room's emotional temperature.

The worksheet format matters because it forces the reframe past a single
word swap into lived justification — connecting the new label to evidence
the person can actually believe. This is a specific application of
[cognitive reframing](cognitive-reframing.md) aimed at [labels that strip
context](labels-strip-context.md), especially stereotype-laden trait names
that have been absorbed as identity verdicts. Pair with [stereotype threat
interacts with mindset](stereotype-threat-and-mindset.md) when the old
labels came from group stereotypes rather than a single critic.

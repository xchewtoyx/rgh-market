---
type: concept
title: Memory Distortion Through Blending
description: >
  Memories are not stored records of past events — each recall blends the
  original event with the emotional coloring and interpretation attached
  at the time, and that blend compounds further with every subsequent
  recall.
sources:
  - title: Solve for Happy
    resource: "Solve for Happy (Mo Gawdat), Part 3, Chapter 9: Is It True?"
---

A memory is a description of what the brain concluded happened, not an
archival recording — and that description is already shaped by whatever
other distortions (filtering, assumption, emotion) were active at the time
the memory formed. Each time a memory is recalled, the current emotional
and interpretive coloring blends further into it, so the memory
accumulates additional distortion across repeated recollection rather than
staying fixed — a location tagged as "sad" after one bad experience there
can bias the interpretation of every subsequent visit, which in turn
reinforces and deepens the original tag.

Because memories feel like direct, reliable evidence about the past, this
compounding is easy to miss — a memory retrieved as support for a current
belief ("this always happens to me," "I've never been good at this") may
be reporting the accumulated emotional coloring of many retellings rather
than the original event with any fidelity. The corrective is to treat a
memory offered as evidence with the same scrutiny given to any other
unverified claim — see [testing a limiting
belief](testing-a-limiting-belief.md) — rather than treating "I remember
it that way" as settling the question.

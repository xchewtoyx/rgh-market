---
type: concept
title: Less Is More Heuristic
description: >
  System 1 averages the quality of items in a set instead of summing them,
  so adding inferior elements can raise subjective value — the same
  averaging mistake distorts probability judgments.
sources:
  - title: Thinking, Fast and Slow
    resource: "Thinking, Fast and Slow (Daniel Kahneman), ch. 16"
---

Christopher Hsee's dinnerware study: Set A (40 pieces, including 7 broken
saucers among 8) strictly dominates Set B (24 intact pieces, a subset of
A's good items). In **joint evaluation**, Set A priced higher ($32 vs.
$30); in **single evaluation**, Set B priced much higher ($33 vs. $23).

System 1 evaluates by the *average* value of items, not the sum — a set
"diluted" by broken dishes looks worse even though it's strictly more
valuable. Hsee's **less is more**: removing items can raise felt worth.

The structural link to [conjunction fallacy](conjunction-fallacy.md):
probability is sum-like (feminist tellers + non-feminist tellers = all
tellers), but averaging makes "feminist bank teller" feel more probable
when non-feminist tellers drop out of consideration — same mechanism as
removing broken dishes raising Set A's appeal. Joint evaluation fixes the
dinnerware error but often not the Linda error, because probability's
sum-like structure is less obvious than money's.

Further replications: Wimbledon rankings where "loses first set but wins
match" beats "loses first set" in felt probability; die-sequence bets
where prepending a green face to a sequence raises preference despite
lowering true odds. When comparing outcomes, force explicit nesting or
frequency counts ("how many?") rather than isolated plausibility.

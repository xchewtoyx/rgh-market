---
type: concept
title: Two-Handles Technique
description: >
  Most situations, especially interpersonal grievances, can be picked up
  by more than one description — an unworkable "handle" that only
  generates resentment, and a workable one that opens a path forward — and
  which one gets used is a choice, not a fact about the situation.
sources:
  - title: "Discourses, Fragments, Handbook"
    resource: "Handbook (Epictetus), chapter 43"
---

The same event can be described in more than one true way, and the
description chosen determines what can be done with it — "everything has
two handles, one by which it can be carried, one by which it can't."
Applied to a grievance: a brother's wrongdoing can be picked up by "he is
wronging me" — a description that is accurate but leads nowhere useful,
since it only supports resentment — or by "he is my brother, we were
raised together" — equally accurate, and a description that actually
opens a path toward reconciliation or a constructive response. Neither
description is false; the choice of which one to reach for is what
determines whether the situation becomes workable.

This is a compact, situation-specific version of [cognitive
reframing](cognitive-reframing.md): rather than disputing whether the
frustrating description is true, it treats truth as compatible with
multiple available framings and asks which one is actually useful to
hold onto given what's wanted next. It's especially suited to
interpersonal friction specifically, where the unworkable handle
("they're being unreasonable," "they don't respect me") is usually just
as factually available as the workable one ("this is someone I care about
and want to stay in relationship with") — the practical move is
noticing, in the moment of picking a situation up, which handle is being
reached for by default, and deliberately reaching for the other one when
the default handle isn't leading anywhere useful.

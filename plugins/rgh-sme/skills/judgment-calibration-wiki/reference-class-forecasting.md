title: Reference Class Forecasting
description: >
  Outside-view method that anchors on distributional statistics from similar
  past cases before adjusting for case-specific factors.
sources:
  - title: Thinking, Fast and Slow
    resource: "Thinking, Fast and Slow (Kahneman), ch. 23"
  - title: User Story Mapping

---

Bent Flyvbjerg: "The prevalent tendency to underweight or ignore distributional
information is perhaps the major source of error in forecasting." Kahneman calls
this the single most important advice for improving forecast accuracy.

**Reference class forecasting** (Flyvbjerg, applied to transportation projects
worldwide):

1. Identify an appropriate reference class (kitchen renovations, large railways).
2. Obtain reference-class statistics (cost per mile, percentage overrun) for a
   baseline prediction.
3. Adjust the baseline using case-specific information if this project likely
   differs from the class average in optimism bias.

Same structure as overcoming [base rate neglect](base-rate-neglect.md): anchor
on the [outside view](inside-view-vs-outside-view.md), then adjust.

Purpose: give authorities realistic cost/benefit views before approval and
estimate budget reserves — though reserves can become self-fulfilling prophecies
("budget reserve is to contractors as red meat is to lions"). For software features
and product bets, analogous classes include unused-feature rates and startup failure
statistics — see [product build outcome base rates](product-build-outcome-base-rates.md).
Organizational
remedy: reward precise execution; penalize both failure to anticipate
foreseeable difficulties and failure to allow for unknowable ones.

---
type: concept
title: Minimize Extraneous Cognitive Load
description: >
  Every visual element costs mental effort; extraneous cognitive load is
  processing that consumes that budget without helping understanding, so
  clutter that makes a graphic look hard can cause the audience to opt out
  before the message is heard.
sources:
  - title: Storytelling with Data
    resource: "Storytelling with Data (Cole Nussbaumer Knaflic), ch. 3"
---

Audience mental processing power is finite. Useful cognitive load is the
effort spent extracting the message; **extraneous cognitive load** is effort
spent on elements that do not help (or actively hinder) understanding — a
busy slide, chrome that must be decoded, a graph abandoned because it *looks*
too hard. Designers should minimize **perceived** cognitive load: audiences
judge how hard a visual will be largely unconsciously, and that judgment can
decide whether they engage at all.

**Clutter** is the practical form of extraneous load: visual elements that
take space without increasing understanding. Clutter makes visuals appear
more complicated than necessary and can produce a subtly uncomfortable
experience that ends in opt-out — at which point communication has failed.
The constructive response is the same discipline as maximizing the
[data-ink ratio](data-ink-ratio.md) (or Duarte's signal-to-noise framing:
signal = information to communicate, noise = everything else): follow
[declutter chart chrome](declutter-chart-chrome.md), use
[alignment and white space](alignment-and-white-space.md), then use
[Gestalt grouping](gestalt-proximity.md) to keep necessary structure without
heavy borders. Declutter before you
[build visual hierarchy](visual-hierarchy-with-preattentive-attributes.md) —
emphasis on a noisy field still fails.

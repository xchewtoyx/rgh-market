title: Preattentive Processing
description: >
  Certain simple visual attributes are recognized almost instantly and below
  conscious awareness, while everything else must be found through slow,
  sequential, conscious search.
sources:
  - title: Information Dashboard Design
    resource: "Information Dashboard Design (Stephen Few), ch. 4 §4.2"
  - title: Storytelling with Data

Preattentive processing is fast and operates below consciousness; attentive
processing is sequential and much slower. A classic demonstration: counting
how many "5"s appear in a grid of digits distinguished only by shape (glyph)
takes noticeably longer — a slow, serial, attentive search — than counting
"5"s that are additionally set apart by color intensity, where they "pop out"
instantly without conscious search. The same contrast appears when counting
"3"s in a plain number block versus the same block with those digits given
higher color intensity — iconic memory is what makes the second version feel
effortless. Complex shapes (like digit glyphs) are not perceived
preattentively; only simple shapes and a limited set of visual attributes
are. Perception mostly happens in the brain, not the eyes: light is captured
by the eyes, but "we don't fully see with our eyes."

Used strategically, preattentive attributes let an audience see what the
designer intends before conscious search begins. That mechanism makes
[dynamic highlighting](static-vs-dynamic-highlighting.md) work on dashboards
— a distinct attribute finds the exception without serial scanning — and it
also supports
[visual hierarchy in explanatory graphics](visual-hierarchy-with-preattentive-attributes.md):
directing attention to a focus and ranking remaining elements so the story is
processed in the intended order. See
[preattentive attributes for dashboards](preattentive-attributes-for-dashboards.md)
for which specific attributes qualify and what each can express.

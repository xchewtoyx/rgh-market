---
type: concept
title: Progressive Emphasis Across Slides
description: >
  The same underlying chart can support different claims by restyling
  preattentive emphasis alone — and in live presentation, revealing or
  highlighting only the relevant slice at each step controls attention
  through the narrative.
sources:
  - title: Storytelling with Data
    resource: "Storytelling with Data (Cole Nussbaumer Knaflic), ch. 4, ch. 8"
---

Once a decluttered base chart exists, **preattentive restyling** — not new
data — can foreground different parts of a nuanced story. Color a launch
event and the series that declined after it for one claim; recolor markers
for a typical post-launch price arc for another; highlight the latest
converged range for a third. Each variant should still pass the eye-path
test for its own
[visual hierarchy](visual-hierarchy-with-preattentive-attributes.md).

In a live presentation, control attention further by **progressive reveal**:
show only the relevant points at each spoken beat, or push everything else
to the background while one piece is emphasized, paired with the spoken
narrative. Start from a blank axes setup when needed so the audience absorbs
scales with the speaker before data appears. Build chronological path product
by product (or series by series), introduce tension, restore balance, and
land on the call to action — the graphic sequence is the consumption design;
the story wording itself belongs with presentation craft.

Avoid the **slideument** failure: one dense view meant to serve both live
walkthrough and circulated takeaway meets neither need. Pair animated
reveal (live) with a fully
[annotated standalone version](action-titles-and-on-chart-annotation.md)
(circulated), ideally from the same deck (final annotated layer prints) or
by circulating only the last slide of a flip-through sequence.

The same pattern scales: treat the overarching deck as the main story and
each visual's emphasis sequence as a subplot. This is the live-presentation
application of
[explanatory vs. exploratory design](visualization-for-exploration-vs-communication.md):
exploration keeps emphasis neutral; communication sequences emphasis
deliberately. Prefer [direct labels](direct-labeling-over-legends.md) on the
base chart so legend chrome does not fight each restyle. For many overlapping
series, see [spaghetti graph strategies](spaghetti-graph-strategies.md).

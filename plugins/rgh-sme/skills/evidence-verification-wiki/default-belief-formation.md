# Default Belief Formation

The intuitive model of belief formation is a three-step sequence: hear a claim, evaluate it, then believe or reject it. Experimental psychology finds the actual sequence is different: **hear a claim, believe it immediately, and only sometimes get around to vetting it afterward.** Believing is closer to involuntary comprehension than to a deliberate rational judgment — under time pressure or cognitive load, people misremember statements they were explicitly told were false as having been true far more often than the reverse, indicating the default "true" tag is what gets stored unless active effort overwrites it.

## Why the Default Runs This Way
For direct sensory experience, assuming a perception is accurate was historically the safer bet — treating a rustling sound as a possible predator costs little if wrong, but disbelieving it can be fatal. Believing first and checking later is an adaptive shortcut for perception. Abstract belief formation through language is evolutionarily much newer and appears to run on the same "believe first" machinery, even though the cost-benefit calculus for an abstract claim (a rumor, a statistic, a claimed mechanism) is completely different from the calculus for a rustling bush.

## Consequences for Verification
This means an unverified claim is not a special, effortful state that requires active work to create — it's the automatic outcome of simply encountering a statement. Verification is not "catching" a claim that's trying to sneak past scrutiny; it's providing a step that does not happen by default and must be deliberately inserted after belief has already formed. This also explains why merely encountering a false claim (even when explicitly labeled as false, as in debunking or correction efforts) can still leave a "believed" trace that outlasts the correction, since the correction has to overwrite an already-formed default belief rather than prevent one from forming in the first place.

## Verification Action
Treat every new claim encountered during authoring or review as provisionally believed by default, not neutrally suspended pending evidence — the practical implication is that a reviewer must deliberately trigger the vetting step for each claim (asking where it came from, how it's known, what would make it false) rather than waiting for something to feel suspicious first, since the default cognitive state produces no such warning signal even for claims that are false.

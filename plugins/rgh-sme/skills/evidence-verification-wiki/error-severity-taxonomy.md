# Error Severity Taxonomy

Not all discovered errors call for the same response. Classifying an error by severity helps a reviewer prioritize which findings need to block publication versus which need only a quiet correction:

1. **Minor cracks**: simple misunderstandings or copy errors — a wrong title, a transposed digit, a misspelled name. Individually low-stakes, but even a small, visible flub makes an observant reader distrust the rest of the document.
2. **Foundation-shaking problems**: oversimplified-to-wrong explanations, credulous sourcing, or gross misunderstanding of context — the kind of error that comes from [cherry-picking](cherry-picking.md), an uncorrected [knowledge bias](knowledge-bias-in-verification.md), or trusting an unreliable source. These undermine a specific section or claim, not just a detail.
3. **Full-blown fabrication**: invented quotes, invented sources, or outright fabricated claims — see [fabrication detection](fabrication-detection.md). These require the most serious response, up to retraction, and often indicate a pattern rather than an isolated mistake.
4. **Source-agreement violations**: publishing material in a way that breaches agreed terms with a source (e.g., using off-the-record material as if it were on the record) — a distinct failure mode from factual inaccuracy, since the underlying fact can be true while the disclosure itself was improper.
5. **Gray-area drift**: unconscious bias or facts reshuffled for narrative flow, without a clear single factual error to point to — the hardest category to catch because no single sentence is straightforwardly false, and a document's author develops blind spots the longer they've worked on a piece, which don't self-correct without outside review.

## Verification Action
When logging a finding, classify it into one of these tiers rather than treating every error as equivalent. A cluster of "minor cracks" in one section can itself be a signal to escalate scrutiny of that section, since a document's error rate is rarely uniform.

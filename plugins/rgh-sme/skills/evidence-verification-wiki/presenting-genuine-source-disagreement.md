# Presenting Genuine Source Disagreement

When multiple *credible* sources genuinely disagree on a fact (dueling eyewitnesses, dueling experts), the correct resolution is not always to pick a winner. One valid outcome is presenting the disagreement itself transparently rather than forcing false certainty onto the document.

This is distinct from [evidence weighting vs. false balance](evidence-weighting-vs-false-balance.md): false balance is giving equal standing to a fringe or unsupported view against an established consensus. Genuine source disagreement is a case where the underlying evidence itself does not resolve cleanly, and multiple credible accounts conflict — no single account should be asserted as ground truth.

## Verification Action
- If a claim is asserted as settled fact in a draft, but independent sourcing turns up several credible parties disagreeing, the wording must be readjusted to reflect that disagreement rather than pick a side by default.
- For sensitive conflicts (e.g., one party's firsthand account vs. an institutional record), explicitly weigh power dynamics when contextualizing the disagreement — consider the track record and incentives of each party, not just how many sources back each account.

title: Gestalt Principles for Visual Grouping
description: >
  Six perceptual tendencies — proximity, similarity, enclosure, closure,
  continuity, and connection — determine which elements a reader
  automatically perceives as belonging together, in a fixed order of
  strength that a document's layout can either exploit or fight against.
sources:
  - title: "Information Dashboard Design"
    resource: "Information Dashboard Design (Stephen Few), ch. 4"

A reader groups visual elements together automatically, before consciously reasoning about the content, according to a handful of perceptual tendencies identified by Gestalt psychology. Laying out a document or diagram with these tendencies in mind means the grouping a reader perceives matches the grouping the writer intended; ignoring them means the layout is fighting the reader's own perception, no matter how logically the content is actually organized.

- **Proximity** — elements placed near each other read as one group. The simplest way to signal "these belong together" is often just white space, with no border or color needed; placing sections closer together horizontally versus vertically can even nudge a reader's scan direction.
- **Similarity** — elements that share a color, size, shape, or orientation read as related, even when they're far apart on the page. Using the same color for the same recurring thing (the same metric, the same category) wherever it appears is how a reader learns to associate that color with that meaning and then uses it to link separated instances back together.
- **Enclosure** — a border or shared background around a set of elements reads as "this is one distinct group," and works even with a subtle border; heavier emphasis than the border needs isn't required for the grouping to register.
- **Closure** — an incomplete shape is still perceived as the complete shape it resembles (a rectangle drawn with gaps in its sides still reads as a rectangle). Practically, this licenses leaving out visual elements that aren't strictly necessary — a chart needs only its two axis lines, not a full box around the plotted area, because the reader's perception closes the implied boundary anyway.
- **Continuity** — elements aligned with each other, or that appear to continue one another, read as a single line or group. Consistent indentation or alignment of items in a list or table can signal grouping (this item is a sub-point of that one) without needing an explicit rule or border to do the same job.
- **Connection** — elements joined by a visible line or connector read as grouped, and this is a stronger cue than either proximity or similarity — weaker only than enclosure. This makes connection especially useful for showing a relationship between elements that aren't near each other and don't share an obvious visual property, such as steps in a process or people in an organization chart.

These six form a rough strength ordering — **enclosure > connection > proximity/similarity** — useful when a layout needs to express more than one grouping at once: the strongest cue should be reserved for the grouping that matters most, since a weaker cue can be overridden by a stronger one used elsewhere on the same page. See [preattentive attributes for rapid visual perception](preattentive-attributes-for-rapid-visual-perception.md) for the lower-level visual properties (color, position, shape) these grouping principles are built from, and [using visuals effectively](using-visuals-effectively.md) for applying this kind of grouping judgment when choosing and laying out a diagram.

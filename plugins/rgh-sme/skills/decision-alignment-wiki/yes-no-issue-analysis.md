title: Yes/No Issue Analysis
description: >
  Treat each decision issue as a yes-or-no question, not a
  topic, so analysis moves efficiently to a recommendation.
sources:
  - title: "The Minto Pyramid Principle: Logic in Writing, Thinking and Problem Solving"
    resource: "The Minto Pyramid Principle (Barbara Minto), ch. 9"
---

An **issue** is a question that can be answered yes or no —
not a topic label ("pricing," "culture," "capacity"). Topic
labels invite open-ended exploration; yes/no issues force a
decisionable claim.

Good issue analysis:
1. Starts from the problem history and the
   [problem-definition-framework](problem-definition-framework.md).
2. States the misconceptions or hypotheses blocking
   resolution.
3. Uses a structured framework
   ([structure-analysis-before-data](structure-analysis-before-data.md))
   so each yes/no answer both isolates causes and shows when
   research is complete.
4. Moves from findings to conclusions to an explicit
   recommendation.

Match issue type to structure:
[diagnostic-versus-decision-structures](diagnostic-versus-decision-structures.md).
This keeps the
[problem-stage-question](problem-stage-question.md) sharp and
avoids documents that inform without deciding.

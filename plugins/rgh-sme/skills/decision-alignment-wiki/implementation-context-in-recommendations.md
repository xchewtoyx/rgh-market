---
type: concept
title: Implementation Context in Recommendations
description: >
  Decision recommendations must name system contribution,
  relationships, politics, and information habits as
  actionable context—not as personal criticism.
sources:
  - title: "Flawless Consulting"
    resource: "Flawless Consulting (Peter Block), ch. 17"
---

A recommendation that describes only the technical fix and
omits how the organization contributes to the problem is
incomplete. Decide what must be said about:

- the client system's contribution to the issue,
- relationships and politics that shape adoption,
- how the organization handles information.

That material is necessary implementation context for
coordinated action and ownership. Framed as system pattern —
not personal attack — it prepares stakeholders for real
commitments in
[managing-alignment-meetings](managing-alignment-meetings.md)
and reduces surprise when
[managing-stakeholder-resistance](managing-stakeholder-resistance.md)
appears.

Pair it with
[observation-interpretation-implication](observation-interpretation-implication.md)
themes so the context stays tied to the decision, not a
side rant.
